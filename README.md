# Time Series Lab

An interactive self-study site for time series analysis. Lessons, live simulations, and short checks cover:

- Time series relationships
- Trend, seasonality, and correlated errors
- Regression with correlated errors
- Autoregressive models
- ARMA models
- Spectral analysis and the periodogram
- Linear filtering
- Prediction
- Transfer function models
- Time series in Unity
- Time series in Godot

Progress and quiz scores stay in the local browser.

## Run locally

Install dependencies, then start the development server from this folder. Open the address the server prints, usually on localhost port 5173.

## Build

Create a production build, then preview the finished site with the project preview command.
