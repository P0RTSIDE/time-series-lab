# Time Series Lab

A browser course in time series analysis, with separate Unity and Godot tracks. Each time series chapter has a written takeaway, a live simulation, and a short check. Lesson progress and quiz scores stay in the browser (`localStorage`).

The Unity and Godot tracks teach an editor, a script, and a small playable loop. They are not time series chapters.

## Time series

1. Time series relationships
2. Trend, seasonality, and correlated errors
3. Regression with correlated errors
4. Autoregressive models
5. ARMA models
6. Spectral analysis and the periodogram
7. Linear filtering
8. Prediction
9. Transfer function models

A playground and a glossary sit outside the numbered sequence.

## Unity

Nine lessons: editor and objects, C#, the update loops, input, physics, prefabs, UI, scenes and game state, then motion, sound, and polish.

## Godot

Nine lessons: nodes and scenes, GDScript, process clocks, input, bodies, instancing, signals and UI, autoload and groups, then motion, sound, and polish.

## Stack

React 19, TypeScript, Vite, and KaTeX.

## Run locally

```bash
npm install
npm run dev
```

The dev server prints a local URL, usually http://localhost:5173.

```bash
npm run build
npm run preview
```
